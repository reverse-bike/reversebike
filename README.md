The Super73 Reverse Engineered project provides comprehensive service documentation for Super73's fat tire e-bikes. The initial focus will be on the R-series and S-series.

Super73 provides very minimal documentation; what exists is focused on use. Their limited warranty discourages modification or disassembly. Many parts are common but with proprietary connections, creating intentional incompatibilities.

This project aims to exercise the [right to repair](https://en.wikipedia.org/wiki/Right_to_repair) by guiding anyone with foundational bicycle knowledge willing to learn more and maintain their e-bike. The ability to repair and maintain extends the life and enjoyment of the e-bike, is economically and ecologically sound, and is incredibly satisfying.

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites

You need to have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Fork the repo
2. Clone the repo
   ```sh
   git clone https://github.com/blopker/reversebike.git
   ```
3. Install NPM packages
   ```sh
   npm install
   ```

### Development

To start the development server, run:

```sh
npm run dev
```

Your site will be available at `http://localhost:4321` (or similar).

### Content layout

The sidebar is generated by Starlight straight from the directory tree under `src/content/docs`, so the layout follows a few rules:

- **Directories are sidebar groups.** A directory's name is used verbatim as its group label, so group directories are title-cased, such as `Components/Electrical` or `Specifications/Bluetooth BLE`. Astro lowercases and hyphenates directory names in URLs, so `Bluetooth BLE` is served at `/specifications/bluetooth-ble/`.
- **Pages are single files.** A leaf page is `some-page.md`, never `some-page/index.md`, since Starlight would render a one-file directory as a group. The file name is the URL slug and the page's `title` is its sidebar label.
- **`index.md` is a group's overview.** It is pinned to the top of its group with `sidebar.order: 0` and labelled "Overview" via `sidebar.label` in its frontmatter.
- **Images live in `_images/`** beside the pages that use them. The leading underscore keeps the directory out of the content collection. Image files are named by their content hash, so copies of the same image share one file.

Top-level section order is set in `astro.config.ts`. Everything inside a section is sorted alphabetically unless a page sets `sidebar.order`.

## 🧞 Commands

All commands are run from the root of the project, from a terminal:

| Command | Action |
| :--- | :--- |
| `npm install` | Installs dependencies |
| `npm run dev` | Starts local dev server at `localhost:4321` |
| `npm run build` | Build your production site to `./dist/` |
| `npm run preview` | Preview your build locally, before deploying |
| `npm test` | Type-check, build, and verify every internal link resolves |
